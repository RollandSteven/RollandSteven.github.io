# Portfolio (free hosting on GitHub Pages)

Run locally: `npm install` then `npm run dev` (http://localhost:3000).

Edit `content/profile.ts` (about, experience) and `content/projects.ts` (add one object per project).

## Deploy for free
1. On GitHub, create a PUBLIC repo named exactly `RollandSteven.github.io`.
2. Push this folder to its `main` branch.
3. Repo Settings > Pages > Source: **GitHub Actions**.
4. After the workflow finishes, the site is live at https://rollandsteven.github.io
